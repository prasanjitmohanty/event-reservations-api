
## Description

This project is using NestJS(https://nestjs.com) A progressive Node.js framework for building efficient, reliable and scalable server-side applications. It helps elevate testability dependency injection system, code modularit. It uses Express.js under the hood.

## Project setup

```bash
$ npm install
```

## Compile and run the project

## Docker
```bash
$ docker-cmpose up

```

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Swagger Endpoint
http://localhost:3000/api

## Run tests

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```
